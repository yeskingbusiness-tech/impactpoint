THE RULES

  • Land hits to build damage % — the higher it climbs, the farther you fly.
  • Knock rivals past the blast zone to take a stock.
  • Run out of stocks and you're eliminated. Last fighter standing wins.
  • Recover with double jumps and up-specials. Don't get greedy off-stage!
  • Shield blocks hits but drains — let it break and you'll be stunned.
  • Dodge rolls make you briefly invincible. Read your opponent.

LAN PLAY

  • One player hosts an arena; others join from the match browser or room code.
  • Everyone on the same network opens this page from the host's address (see the server console).
  • Up to 4 fighters per arena — fill empty slots with CPU players.
